# Activity — See AI's Memory and Context Limits

**Your goal:** watch AI's memory and context limits with your own eyes. (Process over product —
notice the behavior.)

---

## Part 1 — Test the memory

1. Start a fresh chat. Give the AI a strict rule:
   > *"For the rest of this chat, answer everything in exactly one sentence."*
2. Now chat about anything for **many messages** (ask follow-ups, change topics).

**Write down:** did it eventually break the rule? Roughly when?

```
______________________________________________________________________________
```

> 💡 When it slips, that's the context window overflowing — your early rule fell out.

---

## Part 2 — Feed it context

1. Ask for something **vague:** *"Write something about dogs."*
2. Ask again **with context:** goal + audience + length
   (e.g., *"a friendly 100-word intro about dog adoption for a shelter newsletter"*).

**Write down:** which result would you actually use, and why?

```
______________________________________________________________________________
```

---

## Part 3 — Restate and recover

Go back to your Part 1 chat. **Restate the rule** ("remember: one sentence only").

**Write down:** did it recover?

```
______________________________________________________________________________
```

## Discussion questions

1. How does knowing about the context window change how you'd run a long AI conversation?
2. "AI can't read your mind." What context do you tend to leave out that would help it?
3. AI's knowledge is finite and frozen at training time. Where could that bite you?
4. Does understanding images as "fast pixel computation" change how much you trust them?

# Activity — Set Up an Organized Project

**Your goal:** build the bones of one organized project. (Process over product — a simple
structure you'll actually use beats a perfect one you won't.)

---

## Part 1 — One project, one folder

Pick a real effort (a class, a side project, a job task). Make it **one project folder.**

```
My project: __________________________________________________________________
```

---

## Part 2 — Let AI design the structure

Ask a chatbot:

> *"Propose a simple folder structure and a naming convention for a project about [your project]."*

Create the top-level folders it suggests (adjust as you like).

**Write down:** the folders you made.

```
______________________________________________________________________________
```

---

## Part 3 — Start a log + a sandbox

1. Add a **log** file (e.g., `log.md`). Write two lines: *what this project is*, and *what you did
   today.*
2. Add a **`sandbox`** subfolder — your no-stakes place to try risky things from now on.

**Write down:** your two log lines.

```
______________________________________________________________________________

______________________________________________________________________________
```

---

## Reflection (the one thing to take with you)

Finish this sentence:

> **"The one change that would make my work easiest to find is ____________________."**

---

## Discussion questions

1. Why has digital clutter survived even though folders have existed forever? What actually fixes
   it?
2. What belongs in the information architecture for *your* kind of work?
3. A log feels like overhead in the moment. When has *not* having one cost you?
4. What would you feel free to try if you had a real sandbox to break things in?
